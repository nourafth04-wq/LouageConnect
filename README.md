# LouageConnect

> **Plateforme de réservation et de suivi en temps réel pour les louages (taxis collectifs) en Tunisie.**

LouageConnect est une application web conçue pour faciliter la mobilité interurbaine. Elle permet aux utilisateurs de localiser les louages en temps réel sur une carte interactive et de réserver leurs places en toute simplicité.

## ✨ Fonctionnalités principales

- **Authentification** : Inscription et connexion sécurisées des utilisateurs.
- **Suivi en temps réel** : Localisation des louages sur une carte interactive.
- **Gestion des réservations** : Système de réservation fluide avec un tableau de bord utilisateur dédié.
- **Expérience utilisateur** : Interface moderne avec un thème clair et sombre (Dark/Light mode).

## 🛠️ Stack Technique

| Catégorie | Technologies |
| :--- | :--- |
| **Backend** | PHP, MySQL |
| **Frontend** | HTML5, CSS3, JavaScript |
| **Cartographie** | Leaflet (OpenStreetMap) |
